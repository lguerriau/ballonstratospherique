Cliquer sur l'un des 2 boutons en haut pour choisir de voir la TELEMETRIE ou la SSTV

Télémétrie:
Les données se mettent a jour toutes les 10 minutes.
Les 3 cases représent les dernières données relevées
Cliquez sur l'une des cases pour voir les 50 dernières données de cette télémétrie en courbe et horodatée sur le coté

SSTV :
Les photos se mettent à jour après rafraîchissement de la page.
La photo qui à été ajouté dans la base de données en dernier s'affiche en premier sur l'interface.
Cliquez sur le bouton pour générer une vidéo et une vidéo est créée avec les photos de la base de données (environ 1 seconde pour une photo).
